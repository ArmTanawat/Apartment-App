# ไอคอนของแอป

วางไฟล์ **`icon.png`** ไว้ในโฟลเดอร์นี้ แล้ว build ใหม่ — แค่นั้น
`electron-builder` จะแปลงเป็นไอคอนของ Windows และ macOS ให้เอง

| | |
|---|---|
| ชื่อไฟล์ | `icon.png` (ตัวพิมพ์เล็กทั้งหมด) |
| ขนาด | อย่างน้อย 512 × 512 แนะนำ 1024 × 1024 |
| รูปทรง | สี่เหลี่ยมจัตุรัส พื้นหลังโปร่งใสได้ |

ถ้ามีไฟล์ `.ico` หรือ `.icns` ที่ทำไว้แล้ว วางเป็น `icon.ico` / `icon.icns`
ได้เหมือนกัน จะถูกใช้แทนการแปลงจาก PNG

## ไอคอนจะขึ้นตอนไหน

**ต้อง build เป็นตัวติดตั้งก่อน** — `npm run dist:mac` หรือ `npm run dist:win`

`npm start` เปิดแอปจากซอร์สโดยตรง ยังไม่มี bundle ของเราเอง มันจึงยืม
bundle ของ Electron มาใช้ ไอคอนบน Dock กับชื่อบนแถบเมนูจึงเป็นของ Electron
ไฟล์ในโฟลเดอร์นี้เป็น *วัตถุดิบตอนสร้าง* ไม่ได้ถูกอ่านตอนแอปทำงาน

`electron/main.js` ช่วยไว้บางส่วนตอนรันจากซอร์ส — ตั้งชื่อในเมนูและไอคอนบน Dock
ให้ตรงกับของจริง แต่**ชื่อตัวหนาบนแถบเมนูจะยังเป็น Electron อยู่** เพราะ macOS
อ่านค่านั้นจาก bundle ตอนเปิดโปรแกรม เปลี่ยนตอนรันไม่ได้ ไม่ใช่ข้อผิดพลาด

---

โฟลเดอร์นี้คือ `buildResources` ของ `electron-builder` — เป็นที่เก็บของที่ใช้
*ตอนสร้าง* ตัวติดตั้ง ไม่ได้ถูกใส่เข้าไปในตัวแอป
